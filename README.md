# 台股風險燈號追蹤系統

用自己設的規則取代別人給的點位預測。

**起因：** 2026 年 10 月，分析師杜金龍以波浪理論推估台股 2027 年 5 月可能挑戰 53,000–60,000 點，
並計畫在該時點前後把持股降到 5 成以下。這套系統不預測點位，改用可觀察的風險指標與固定的
減碼階梯來做同一件事。

## 現在的狀態

看 **[CHECKLIST.md](CHECKLIST.md)** — 每天自動更新。

## 三份核心文件

| 文件 | 內容 |
|---|---|
| [CHECKLIST.md](CHECKLIST.md) | 每日追蹤表。十個指標的燈號、風險分數、建議動作。自動產生。 |
| [docs/risk-indicators.md](docs/risk-indicators.md) | 十大指標的定義、權重排序理由、資料來源、已知限制。 |
| [docs/ladder.md](docs/ladder.md) | 階梯式減碼表、風險分數覆蓋規則、下行回補階梯、三種情境的事前計畫。 |

## 通知規則

**每個交易日收盤後檢查一次。只有燈號變化時才通知。**

- 燈號沒變 → 更新檔案，不發通知。
- 任何一個指標由 🟢 轉 🔴 或由 🔴 轉 🟢 → 發推播，說明哪一個指標變了、新的風險分數、對應動作。
- 資料由 ⚪ 轉為有值，不算燈號變化，不通知。

這個規則是刻意的。每天收到「一切正常」的通知，三週後你就不會再讀它。

## 每天怎麼跑

### 自動（已設定）

排程在台北時間每週一至週五 16:47 執行。它會抓當日數據、更新燈號、提交到這個 repo，
只在燈號變化時推播。

### 手動補資料

有五個指標需要你從看盤軟體輸入，因為雲端環境的網路政策擋住了證交所的網域：

```bash
python3 scripts/risk_check.py --set \
  bias_240=27.4 \
  foreign_net_20d=-2800 index_below_ma20=true \
  dist_from_60d_high=1.2 down_days_20=9 \
  index_new_60d_high=false vol20_vs_prev_peak=95 \
  yield_gap=0.8 dividend_yield=2.3 bond_yield_10y=1.5
```

數值會存在 `data/state.json`，下次執行會沿用，所以只需要在數字有變化時重新輸入。

### 其他指令

```bash
python3 scripts/risk_check.py --show          # 看目前儲存的狀態
python3 scripts/risk_check.py --set pb=4.6 --dry-run   # 試算，不寫檔
python3 scripts/gen_indicator_doc.py          # 改過 config.json 後重新產生說明文件
```

## 十大指標與資料取得方式

| # | 指標 | 權重 | 自動抓取 | 來源 |
|---|---|---|---|---|
| 1 | 大盤股價淨值比 PB | 15 | ✅ | 財報狗、證交所月報 |
| 2 | 融資餘額動能 | 14 | ✅ | 證交所融資融券餘額 |
| 3 | 大盤本益比 PE | 13 | ✅ | 財報狗、證交所月報 |
| 4 | 年線乖離率 | 11 | ❌ 手動 | 看盤軟體（加權指數 + 240MA） |
| 5 | 台積電集中度 | 10 | 部分 | 證交所市值比重（月頻） |
| 6 | 外資 20 日累計賣超 | 9 | ❌ 手動 | 證交所三大法人統計 |
| 7 | 市場廣度惡化 | 8 | ❌ 手動 | 證交所漲跌家數 |
| 8 | 量價背離 | 7 | ❌ 手動 | 看盤軟體 20 日均量 |
| 9 | 股債利差 | 7 | ❌ 手動 | 證交所殖利率月報、公債殖利率 |
| 10 | 當沖投機熱度 | 6 | 部分 | 證交所月統計 |

**要讓 4、6、7、8、9 也自動化**，需要在雲端環境的設定裡把 `www.twse.com.tw` 與
`openapi.twse.com.tw` 加進允許的網域。目前這兩個網域被網路政策阻擋。
設定位置在工作階段標題列的雲端環境選單 → Edit → Network access。
做法見 <https://code.claude.com/docs/en/cloud-environments#network-access>。

## 檔案結構

```
CHECKLIST.md                  每日追蹤表（自動產生，不要手改）
docs/risk-indicators.md       指標說明（由 config.json 產生，不要手改）
docs/ladder.md                階梯減碼表（手寫，可依自己狀況調整）
data/config.json              門檻、權重、配置設定 ← 唯一的設定來源
data/state.json               上次的燈號與數值（用來比對變化）
data/history.csv              每日紀錄，可回測門檻是否合理
scripts/risk_check.py         燈號引擎
scripts/gen_indicator_doc.py  指標說明產生器
```

## 設計原則

1. **規則先寫，不事後解釋。** 門檻存在 `config.json`，改動會留在 git 歷史裡。想降低門檻讓
   自己好過，會被記錄下來。
2. **只有紅綠兩態。** 不設「橙燈」。中間狀態會變成拖延的藉口。
3. **分數優先於點位。** 體質壞掉時價格可能還在漲，但那段漲幅的風險報酬比很差。
4. **只在變化時通知。** 降低雜訊，保留訊號的注意力價值。
5. **誠實標註資料落差。** 每個指標顯示資料日期。月頻資料最多落後一個月。

---

> 這是個人紀律工具，不是投資建議。所有門檻與比重都是可調參數。
> 最終的部位決定要看自己的資金期限、現金需求與可承受的回撤。
